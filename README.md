## Hi, I'm Tianda Sun

Final-year **Computer Science PhD candidate at the University of York**, working on
**LLM reasoning and agentic tool use**, with research in evaluation,
RL post-training, and mechanistic interpretability.

### Selected conference papers

- **Peak-Then-Collapse and the Four Interface Channels of Knowledge-Graph Tool Use** — **EMNLP 2026 Main Conference**. GRPO post-training, training-collapse diagnosis, and interface feedback.
  [ACL Anthology](https://aclanthology.org/2026.emnlp-main.443/) · [arXiv](https://arxiv.org/abs/2605.26037) · [Code](https://github.com/TiandaSun/KG_GRPO)
- **Kinship Data Benchmark for Multi-hop Reasoning (KinshipQA)** — **Findings of EMNLP 2026**. Procedurally generated evaluation across seven kinship systems and up to six reasoning hops.
  [ACL Anthology](https://aclanthology.org/2026.findings-emnlp.274/) · [arXiv](https://arxiv.org/abs/2601.07794) · [Code](https://github.com/TiandaSun/Kinship-Data-Benchmark-for-Multi-hop-Reasoning)

### Preprints under review

- **Tool-Call Dependency Structure is Linearly Decodable in LLM Agent Residual Streams** — probing runtime dependency representations with controlled experiments and activation patching.
  [arXiv preprint](https://arxiv.org/abs/2605.25310) · [Code](https://github.com/TiandaSun/toolcall-dependency-probe)
- **From Target Selection to Condition Reuse: Auditing Residual Interventions in Tool-Use Models** — auditing residual interventions in Qwen3.5-27B across 32 fresh worlds, distinguishing familiar target selection from condition reuse, independent judgments, and complete actions.
